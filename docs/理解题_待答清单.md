### 第 2 步 · MyToken（2026-08-17 已讲，检验 2.5/3）
| 题 | 核心结论 |
|---|---|
| Q1 增发 vs 金库转账 | 央行印钞 vs 公司拨款：`_mint` 使 totalSupply 变大、金库永不枯竭（通胀）；`transfer` 总量不变但金库会领空。测试网选增发=可用性优先 |
| Q2 `20 ether` 字面量 | 与 ETH 无关，纯数字后缀 ×10¹⁸；`gwei`=×10⁹；decimals=6（USDC 型）写 `20 * 10 ** 6` |
| Q3 calldata + custom error | calldata=交易只读区零拷贝（memory 要花 gas 抄一份）；custom error 结构化、省 gas、可 `revertedWithCustomError().withArgs()` 校验参数 |

### 第 3 步 · TaskEscrow（2026-08-17 已讲，检验 1/3 → 需重点复述）
| 题 | 核心结论 |
|---|---|
| Q1 重入攻击 | 恶意合约在**收到钱那一瞬间**的 `receive()` 里回调原函数（The DAO 事件 360 万 ETH）；防线=CEI 顺序（先改状态再转账）+ `nonReentrant` 双保险 |
| Q2 `==` vs `>=` | 多付的钱没有任何函数能取出 → **死钱**永久锁死；`==` 是 fail fast 哲学 |
| Q3 规则路由 vs 权限门禁 | 退款地址写 `t.publisher`（发布时定死的链上记录），与 `msg.sender`（谁按按钮）无关；所以任何人可调 `claimTimeout` 却偷不走钱；Web2 后端不敢不鉴权，因为参数可伪造、链上规则不可篡改 |

## 🗣️ 面试话术库（随进度累积）

- **代币设计**：「水龙头我选通胀模型而非金库模型——测试网诉求是可用性不是稀缺性；生产环境要配总量控制。」
- **重入防线**：「所有转账函数遵循 Checks-Effects-Interactions 并加 ReentrancyGuard 双保险——The DAO 的教训写进每一行。」
- **链上 vs Web2 结算**：「Web2 信任『谁在调接口』，链上信任『规则本身』——我的 claimTimeout 是 permissionless keeper 模式，资金路由由代码决定，与调用者身份无关。」
- **费率实现**：「Solidity 无浮点，0.1%/6%/0.5% 全用基点整数 bps（10/600/50 per 10000），链上金额永远整数运算。」
- **三层漏斗**：「召回要便宜、精排要准、重排要懂业务——V0 tag 硬匹配全量兜底、V1 TF-IDF 砍不相关、V2 CTR 在线学习闭环。每层解决上一层的遗留问题，这是工业界推荐系统的标准分层。」
- **双写对账**：「长文本上链太贵，先落库草稿、钱包再质押——Relayer 按 publisher+priceWei 合体，价格是天然对账钥匙；服务器宕机靠启动补账按链重建，链是唯一真相源。」
- **手写算法**：「TF-IDF、逻辑回归 SGD、RESP 协议三样全是手写的——我能从公式讲到代码再讲到生产替换点；造轮子是为了面试讲得清，注释里标了全部替换方案。」
- **冷启动哲学**：「五维分无数据给中性 50、V0 洗牌选 3、V2 空权重给 0.5 先验——新人不该被算法惩罚，否则市场永远只推老 Agent。」

## 🧗 踩坑记录（结业写进项目总结）

| 坑 | 症状 | 解法 |
|---|---|---|
| chai 匹配器链式 | `changeTokenBalances/changeEtherBalances cannot be chained after emit` | 快照型匹配器只能当链首；事件+余额断言拆两条 expect，交易 Promise 存变量（Promise 可多次 await） |
| Number × BigInt 混算 | `Cannot mix BigInt and other types` | **本项目已犯 4 次**（TaskEscrow 测试 ×2、demo-flow.js ×1、relayer.js 的 `MYT()` ×1）：`time.latest()`/`Date.now()/1000`/普通数字字面量返回 Number，与 BigInt 运算前先 `BigInt()` 显式转换；且混进一个表达式的**每一项**都得是 BigInt（demo-flow 的 `BigInt(x) + 3*24*3600` 右边还是 Number，照样炸）。铁律：写完一行含 `n` 后缀的式子，整行扫一遍有没有裸的 Number |
| **空 catch 静默吞错**（第 4 次 BigInt 的放大器） | relayer 补账日志打了"奖励已记"，库里却 0 行——`MYT()` 里 `n * 10n**18n` 的 Number×BigInt 抛 TypeError，被 `creditAirdrop` 的空 `catch {}` 吞成静默失败 | 手工 sqlite3 复现才定位。规矩：**永远不写空 catch**，至少 `console.error`；catch 里只静默明确预期的那种错（如 UNIQUE 冲突），其余必须冒出来 |
| Hardhat 不自动读 .env | Sepolia 部署报 `Cannot read properties of undefined (reading 'address')`（signer 空） | Hardhat 2.29 **不会**自动加载 .env，dotenv 也不是其依赖——`npm i dotenv` + config 顶部 `require("dotenv").config()`；私钥统一 `0x` 前缀再填进 accounts |
| Node fetch 不走系统代理 | verify 报 `Connect Timeout Error`（Etherscan API 直连被墙） | Node 的 undici fetch 默认不理 https_proxy——命令前加 `NODE_USE_ENV_PROXY=1 https_proxy=http://127.0.0.1:7890`（终端已开 Clash 时）。以后 verify 一律带这串前缀 |
| API Key 粘贴吞字 | `Invalid API Key (#err2)`——key 首字母 A 被吞 | key 别手敲手粘，从旧项目 `.env` 里 grep 出来核对首尾字符；web3-university 那把是 `A3D1S…` 开头 |
